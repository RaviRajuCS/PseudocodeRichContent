Two-dimensional arrays

A two-dimensional array organises values using two indices, often representing rows and columns.

PurposeSyntaxExamplesPractice & test

1 · Purpose

A two-dimensional array organises same-type values by two indices, commonly representing rows and columns. Nested loops can process every cell: one loop selects a row and the inner loop visits each column.

Core principle: Declare both index ranges explicitly.

2 · Syntax and worked examples

Formal syntax

DECLARE Grid : ARRAY[rowLower:rowUpper, colLower:colUpper] OF <type>
Grid[row, column]
  • Declare both index ranges explicitly.
  • Use two indices for each element, in the declared order.
  • A nested loop is appropriate when every row-column combination must be processed.
  • Keep row and column bounds distinct to avoid transposed or out-of-range access.

Worked examples with reasoning

Worked example 1 · Declare a table
DECLARE Scores : ARRAY[1:3, 1:4] OF INTEGER
Scores[2,3] ← 87

There are 3 rows and 4 columns; Scores[2,3] is row 2, column 3.

Worked example 2 · Input every cell
FOR Row ← 1 TO 3
  FOR Col ← 1 TO 4
    INPUT Scores[Row, Col]
  NEXT Col
NEXT Row

The inner loop visits four columns for each row, giving 3 × 4 = 12 inputs.

Worked example 3 · Total all cells
Total ← 0
FOR Row ← 1 TO 3
  FOR Col ← 1 TO 4
    Total ← Total + Scores[Row, Col]
  NEXT Col
NEXT Row

The total is updated for each of the twelve cells.

Common examination errors

  • Using only one index for a 2D element.
  • Reversing row and column bounds or forgetting one NEXT.
  • Putting the column loop outside when the intended algorithm depends on row-by-row processing (which may be valid, but changes traversal order).

Trace indices

Five progressive worked examples

Worked example 4 · Extension

Visit every cell

FOR Row ← 1 TO 3
  FOR Col ← 1 TO 4
    OUTPUT Grid[Row, Col]
  NEXT Col
NEXT Row

Reasoning: Three rows by four columns means twelve visits.

Worked example 5 · Extension

Calculate each row total

FOR Row ← 1 TO 3
  RowTotal ← 0
  FOR Col ← 1 TO 4
    RowTotal ← RowTotal + Marks[Row, Col]
  NEXT Col
  OUTPUT RowTotal
NEXT Row

Reasoning: Reset RowTotal for each row before adding its values.
