Nested IF statements

A nested selection places one IF structure inside another selection branch.

PurposeSyntaxExamplesPractice & test

1 · Purpose

A nested IF is an IF statement inside another IF branch. It is useful when a second decision only matters after the first condition has been satisfied. Indentation and ENDIF matching are critical.

Core principle: Trace the outer condition first; only then evaluate the inner condition if execution reaches it.

2 · Syntax and worked examples

Formal syntax

IF <condition1> THEN
  IF <condition2> THEN
    ...
  ELSE
    ...
  ENDIF
ELSE
  ...
ENDIF
  • Trace the outer condition first; only then evaluate the inner condition if execution reaches it.
  • Each IF needs its own matching ENDIF.
  • Indentation shows which ELSE belongs to which IF.
  • Avoid unnecessary nesting when a single compound condition would be clearer.

Worked examples with reasoning

Worked example 1 · Eligibility then age band
IF HasPermission = TRUE THEN
  IF Age >= 18 THEN
    OUTPUT "Full access"
  ELSE
    OUTPUT "Restricted access"
  ENDIF
ELSE
  OUTPUT "Access denied"
ENDIF

If permission is FALSE, the age test is never reached.

Worked example 2 · Highest of two scores
IF ScoreA > ScoreB THEN
  OUTPUT "A wins"
ELSE
  IF ScoreB > ScoreA THEN
    OUTPUT "B wins"
  ELSE
    OUTPUT "Draw"
  ENDIF
ENDIF

The inner IF handles the case where A did not win; it distinguishes B winning from a tie.

Worked example 3 · Tiered result
IF Mark >= 80 THEN
  Grade ← "A"
ELSE
  IF Mark >= 60 THEN
    Grade ← "B"
  ELSE
    Grade ← "C"
  ENDIF
ENDIF

Conditions are tested in order. The second test is reached only if Mark is below 80.

Common examination errors

  • Matching an ELSE with the wrong IF.
  • Missing an ENDIF or using indentation that hides the structure.
  • Checking a broad condition before a narrower condition in a way that makes the narrower branch unreachable.

Independent practice · reveal guidance after attempting

Trace paths

For the eligibility example, trace HasPermission=FALSE and Age=20. Which outputs?

Check your response: Access denied; the inner age test is skipped.

Design a tie

Write nested selection for comparing A and B, including a draw.

Check your response: Compare A>B, else compare B>A, else output draw.

Simplify

A nested structure checks Mark >= 50 and then Mark >= 80. Explain when the inner condition is reached.

Check your response: Only when Mark < 50 if nested in the ELSE; order and nesting determine logic.

Cambridge-style examination challenge

AS Mastery Extension · Deeper learning

This extension moves beyond recognising a statement. Students should be able to select it for a scenario, trace it, identify faulty logic, justify design choices and write a complete solution using Cambridge conventions.

Five progressive worked examples

Worked example 4 · Extension

Apply staged eligibility

IF Age >= 16 THEN
  IF Consent = TRUE THEN
    OUTPUT "Eligible"
  ELSE
    OUTPUT "Consent required"
  ENDIF
ELSE
  OUTPUT "Too young"
ENDIF

Reasoning: The inner decision is reached only if the outer condition is true.

Worked example 5 · Extension

Nested threshold

IF Mark >= 50 THEN
  IF Mark >= 80 THEN
    OUTPUT "Distinction"
  ELSE
    OUTPUT "Pass"
  ENDIF
ELSE
  OUTPUT "Fail"
ENDIF

Reasoning: Trace the outer IF first, then the inner IF.
