Relational and logical operators

Relational operators compare values. Logical operators combine or invert conditions.

PurposeSyntaxExamplesPractice & test

1 · Purpose

Relational operators compare values and return a BOOLEAN. Logical operators combine Boolean conditions. They let algorithms express ranges, eligibility rules and compound decisions precisely.

Core principle: A comparison evaluates to TRUE or FALSE.

2 · Syntax and worked examples

Formal syntax

Relational: >  <  >=  <=  =  <>
Logical: AND  OR  NOT
  • A comparison evaluates to TRUE or FALSE.
  • AND is true only when both conditions are true; OR is true when at least one is true; NOT reverses a Boolean.
  • Use parentheses in complex conditions to make the intended grouping clear.
  • A range such as 0 to 100 inclusive needs Score >= 0 AND Score <= 100.

Worked examples with reasoning

Worked example 1 · Inclusive range
IF Score >= 0 AND Score <= 100 THEN
  OUTPUT "Valid"
ELSE
  OUTPUT "Invalid"
ENDIF

Both comparisons must be true, so -1 and 101 are rejected while 0 and 100 are accepted.

Worked example 2 · Either condition
IF Member = TRUE OR Age >= 65 THEN
  OUTPUT "Discount applies"
ENDIF

Either membership or age eligibility is enough.

Worked example 3 · Negating a condition
IF NOT (Answer = "Y") THEN
  OUTPUT "Confirmation required"
ENDIF

NOT reverses the truth value of the parenthesised comparison.

Common examination errors

  • Using OR instead of AND for a range check; that can make almost every value pass.
  • Confusing assignment ← with comparison =.
  • Leaving out parentheses in a complex condition and misreading operator grouping.

Independent practice · reveal guidance after attempting

Truth reasoning

If A is TRUE and B is FALSE, evaluate A AND B, A OR B, and NOT B.

Check your response: FALSE, TRUE, TRUE.

Repair a range

A mark is valid from 0 to 100. A student uses Mark >= 0 OR Mark <= 100. Explain the fault and correct it.

Check your response: Use AND: both limits must be satisfied.

Combine rules

A user is allowed access if they are an administrator OR their account is active AND verified. Write a clearly parenthesised condition.

Check your response: IF IsAdmin = TRUE OR (IsActive = TRUE AND IsVerified = TRUE) THEN ...; clarify rule grouping.

Cambridge-style examination challenge

Question: Write a Boolean condition that is TRUE only when Temperature is above 10 and at most 25. (2 marks)
