One-dimensional arrays

A one-dimensional array stores multiple values under one name, accessed using an index.

PurposeSyntaxExamplesPractice & test

1 · Purpose

A one-dimensional array stores a fixed number of values of the same data type under one identifier. Each element is accessed with an index. Arrays are useful for collections such as class marks that need to be processed repeatedly.

Core principle: State the lower and upper bounds explicitly; Cambridge commonly uses a lower bound of 1.

2 · Syntax and worked examples

Formal syntax

DECLARE Name : ARRAY[lower:upper] OF <type>
Name[index] ← value
  • State the lower and upper bounds explicitly; Cambridge commonly uses a lower bound of 1.
  • An index must be within the declared bounds.
  • Use a loop to initialise or process many elements; do not assign a range of elements as if it were one element.
  • The array has fixed length and all elements share the declared type.

Worked examples with reasoning

Worked example 1 · Declare and store
DECLARE Marks : ARRAY[1:5] OF INTEGER
Marks[1] ← 78
Marks[2] ← 64

Marks[1] and Marks[2] are distinct elements. The first index is 1 in this declaration.

Worked example 2 · Input five marks
FOR Index ← 1 TO 5
  INPUT Marks[Index]
NEXT Index

The loop uses each valid index once to fill the array.

Worked example 3 · Find a total
Total ← 0
FOR Index ← 1 TO 5
  Total ← Total + Marks[Index]
NEXT Index
OUTPUT Total

Initialise the accumulator before adding each array element.

Common examination errors

  • Using index 0 for ARRAY[1:5].
  • Looping to 6 and accessing an out-of-range element.
  • Forgetting to initialise Total to 0.
  • Confusing an array’s index with the value stored at that index.

Worked example 4 · Extension

Calculate an array total

Total ← 0
FOR I ← 1 TO 5
  Total ← Total + Marks[I]
NEXT I

Reasoning: Each array element contributes once to the total.

Worked example 5 · Extension

Search sequentially

Found ← FALSE
I ← 1
WHILE I <= N AND Found = FALSE
  IF Data[I] = Target THEN
    Found ← TRUE
  ELSE
    I ← I + 1
  ENDIF
ENDWHILE

Reasoning: Stop when found or when all valid indices have been checked.
