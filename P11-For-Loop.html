FOR loop

A FOR loop repeats a block a controlled number of times using a loop variable.

PurposeSyntaxExamplesPractice & test

1 · Purpose

A FOR loop repeats a known number of times or over a defined counter range. It is suitable when the number of repetitions is known, such as processing every item in a fixed-size array.

Core principle: The counter takes the specified sequence of values, including the end value when reached.

2 · Syntax and worked examples

Formal syntax

FOR <counter> ← <start> TO <end> [STEP <increment>]
  <statements>
NEXT <counter>
  • The counter takes the specified sequence of values, including the end value when reached.
  • Use STEP for increments other than 1, including negative steps for a descending sequence.
  • The loop body executes once for each counter value in the sequence.
  • Do not change the loop counter inside the loop body unless the prescribed task explicitly requires it.

Worked examples with reasoning

Worked example 1 · Count 1 to 5
FOR I ← 1 TO 5
  OUTPUT I
NEXT I

Outputs 1, 2, 3, 4, 5: five iterations.

Worked example 2 · Accumulate five values
Total ← 0
FOR I ← 1 TO 5
  INPUT Value
  Total ← Total + Value
NEXT I
OUTPUT Total

Total must be initialised before the loop; each input contributes once.

Worked example 3 · Descending loop
FOR I ← 10 TO 2 STEP -2
  OUTPUT I
NEXT I

Outputs 10, 8, 6, 4, 2. The step is negative and reaches the endpoint.

Common examination errors

  • Off-by-one errors such as stopping at 4 when five items must be processed.
  • Forgetting NEXT or mismatching the counter name.
  • Failing to initialise an accumulator before the loop.
  • Using a FOR loop when the number of repetitions depends on an unknown stopping event.

Count iterations

Check your response: Four iterations: 3, 5, 7, 9.

Array processing

Write a loop to output all elements of Marks[1:30].

Check your response: FOR Index ← 1 TO 30; OUTPUT Marks[Index]; NEXT Index.

Select a loop

A password must be entered until correct. Explain why FOR is usually unsuitable.

Check your response: The number of attempts is not known in advance; a condition-controlled loop is more suitable.

Worked example 4 · Extension

Accumulate a total

Total ← 0
FOR I ← 1 TO 4
  Total ← Total + I
NEXT I
OUTPUT Total

Reasoning: Total progresses 1, 3, 6, 10; final result is 10.

Worked example 5 · Extension

Nested loops

FOR Row ← 1 TO 3
  FOR Col ← 1 TO 2
    OUTPUT Row, Col
  NEXT Col
NEXT Row

Reasoning: The inner statement executes six times in total.
