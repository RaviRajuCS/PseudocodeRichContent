Algorithm tracing

Tracing follows an algorithm line by line and records how variable values and outputs change.

PurposeSyntaxExamplesPractice & test

1 · Purpose

Tracing means executing an algorithm manually with chosen input values and recording how variable values and output change. A dry-run table helps expose incorrect assumptions, off-by-one errors and logic faults before code is run.

Core principle: Start with declared or input values; do not assume variables retain values from a previous run.

2 · Syntax and worked examples

Formal syntax

For each executed line, record the variables changed and any output produced.
  • Start with declared or input values; do not assume variables retain values from a previous run.
  • Update a variable only when its assignment executes.
  • For loops, record every iteration and the counter value.
  • For selection, record the condition result and follow only the chosen branch.
  • Distinguish the final variable state from the sequence of outputs.

Worked examples with reasoning

Worked example 1 · Sequential assignments
A ← 3
B ← A + 4
A ← B * 2
OUTPUT A, B

Trace: A=3; then B=7; then A=14; output 14, 7.

Worked example 2 · Trace a loop
Total ← 0
FOR I ← 1 TO 3
  Total ← Total + I
NEXT I
OUTPUT Total

After I=1, Total=1; I=2, Total=3; I=3, Total=6; output 6.

Worked example 3 · Trace selection
X ← 8
IF X MOD 2 = 0 THEN
  OUTPUT "Even"
ELSE
  OUTPUT "Odd"
ENDIF

8 MOD 2 is 0, so the condition is TRUE and only “Even” is output.

Common examination errors

  • Updating variables in the trace before the corresponding line executes.
  • Skipping a loop iteration or forgetting to reset a variable before a repeated task.
  • Executing both IF branches instead of only the selected branch.
  • Confusing the order of values in an OUTPUT statement.

Independent practice · reveal guidance after attempting

Make a trace table

Trace X ← 2; Y ← X + 5; X ← Y - 1; OUTPUT X,Y.

Check your response: X=2; Y=7; X=6; output 6,7.

Count loop passes

Trace FOR I ← 2 TO 6 STEP 2 and list each I.

Check your response: 2, 4, 6: three iterations.

Explain a branch

For N=11, trace IF N MOD 2 = 0 THEN... ELSE...

Check your response: The condition is false; follow ELSE.
