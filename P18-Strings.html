String manipulation

String operations examine or transform text, for example by finding its length or extracting characters.

PurposeSyntaxExamplesPractice & test

1 · Purpose

A STRING is a sequence of characters. Algorithms can inspect its length, extract a section, change character case or join strings. Index positions and the exact function specification must be read carefully.

Core principle: String literals use double quotation marks; a single CHAR uses single quotation marks.

2 · Syntax and worked examples

Formal syntax

Length: LENGTH(Text)
Extract: RIGHT(Text, n), MID(Text, start, length)
Join: Text1 & Text2
Case: UCASE(Character), LCASE(Character)
  • String literals use double quotation marks; a single CHAR uses single quotation marks.
  • The concatenation operator & joins strings.
  • MID uses a starting position and a number of characters, according to the guide.
  • Check that requested positions and lengths make sense for the string.

Worked examples with reasoning

Worked example 1 · Concatenate strings
FullName ← FirstName & " " & LastName

The space is included as a literal string between the names.

Worked example 2 · Extract a suffix
Code ← RIGHT("CS9618", 4)

Returns the rightmost four characters: "9618".

Worked example 3 · Extract by position
Part ← MID("ABCDEFGH", 2, 3)

Returns "BCD" using the guide’s one-based example.

Common examination errors

  • Using + to concatenate strings in Cambridge pseudocode; the guide uses &.
  • Confusing the number of characters to return with the ending index.
  • Using single quotes for a full string instead of a single character.
