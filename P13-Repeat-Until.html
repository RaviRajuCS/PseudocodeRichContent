REPEAT ... UNTIL

A REPEAT ... UNTIL loop is a post-condition loop: its body runs before the condition is tested.

PurposeSyntaxExamplesPractice & test

1 · Purpose

REPEAT executes the body before testing its termination condition. Therefore the body always executes at least once. It is particularly useful for input and validation where a first attempt is required.

Core principle: UNTIL terminates the loop when its condition becomes TRUE.

2 · Syntax and worked examples

Formal syntax

REPEAT
  <statements>
UNTIL <Boolean condition>
  • UNTIL terminates the loop when its condition becomes TRUE.
  • The condition is checked after the body, so at least one iteration occurs.
  • This is the opposite stopping sense from WHILE: WHILE continues while TRUE; REPEAT continues until TRUE.
  • Design the body so the condition can eventually become true.

Worked examples with reasoning

Worked example 1 · Password retry
REPEAT
  OUTPUT "Enter password"
  INPUT Password
UNTIL Password = "Secret"

The prompt and input occur at least once; correct input ends repetition.

Worked example 2 · Validate a mark
REPEAT
  INPUT Mark
UNTIL Mark >= 0 AND Mark <= 100

The loop ends only when both range conditions are true.

Worked example 3 · Menu choice
REPEAT
  OUTPUT "1 Start, 2 Help, 3 Quit"
  INPUT Choice
UNTIL Choice >= 1 AND Choice <= 3

An invalid choice causes another prompt; valid endpoints 1 and 3 are accepted.

Common examination errors

  • Writing UNTIL condition as though it were WHILE: the stopping condition must be TRUE.
  • Assuming the body might not run; it always runs at least once.
  • Using an invalid-range condition such as Mark < 0 OR Mark > 100 as the UNTIL condition when the intention is to stop on valid input.

For a valid mark, should UNTIL use Mark >= 0 AND Mark <= 100 or Mark < 0 OR Mark > 100?
