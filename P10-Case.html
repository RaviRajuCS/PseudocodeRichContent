CASE ... OF

CASE selects one of several branches using the value of an expression or selector.

PurposeSyntaxExamplesPractice & test

1 · Purpose

CASE chooses one branch according to the value of a single identifier. It is often clearer than a long chain of IF statements when selecting among discrete options or defined ranges.

Core principle: The selector is evaluated and the matching case is selected; after that branch, execution continues after ENDCASE.

2 · Syntax and worked examples

Formal syntax

CASE OF <identifier>
  <value> : <statement(s)>
  OTHERWISE : <statement(s)>
ENDCASE
  • The selector is evaluated and the matching case is selected; after that branch, execution continues after ENDCASE.
  • Use OTHERWISE last when an unmatched value needs handling.
  • A case value may be a range such as 1 TO 5.
  • Use IF for complex conditions involving several variables; CASE is based on the value of one selector.

Worked examples with reasoning

Worked example 1 · Menu option
CASE OF Choice
  1 : OUTPUT "New game"
  2 : OUTPUT "Load game"
  3 : OUTPUT "Quit"
  OTHERWISE : OUTPUT "Invalid choice"
ENDCASE

Choice 2 selects only “Load game”; choice 4 uses OTHERWISE.

Worked example 2 · Range cases
CASE OF Mark
  0 TO 39 : Grade ← "U"
  40 TO 59 : Grade ← "C"
  60 TO 79 : Grade ← "B"
  80 TO 100 : Grade ← "A"
  OTHERWISE : Grade ← "Invalid"
ENDCASE

The ranges should not overlap or leave unintended gaps.

Worked example 3 · Map a code
CASE OF Direction
  "N" : OUTPUT "North"
  "S" : OUTPUT "South"
  "E" : OUTPUT "East"
  "W" : OUTPUT "West"
  OTHERWISE : OUTPUT "Unknown"
ENDCASE

The selector can be a character or string value, provided the values match the data.

Common examination errors

  • Forgetting ENDCASE.
  • Placing OTHERWISE before the specific cases.
  • Overlapping or incomplete numeric ranges.
  • Using CASE for a decision that depends on several unrelated Boolean conditions.

Worked example 4 · Extension

Use OTHERWISE

CASE OF Choice
  1 : OUTPUT "Start"
  2 : OUTPUT "Help"
  3 : OUTPUT "Exit"
  OTHERWISE : OUTPUT "Invalid"
ENDCASE

Reasoning: OTHERWISE handles values that match no earlier case and must be last.
