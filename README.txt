PSEUDOCODE LEARNING HUB — Cambridge 9618 / Year 11

CONTENTS
- index.html: searchable statement/construct directory
- 24 dedicated lesson pages: P01–P24

HOW TO USE
1. Extract the ZIP file into a folder.
2. Open index.html in a modern browser.
3. Select any green lesson link.
4. Upload the extracted files to the root of a GitHub repository to publish with GitHub Pages.

DESIGN
Golden yellow background (#F4C842), parrot-green foreground (#247A35), glassmorphism cards and links. CSS and JavaScript are embedded in every HTML page. No external fonts, libraries, images, APIs, or network connections are required.

ACADEMIC NOTE
The 24-page directory is an instructional organisation, not an official Cambridge list of statements. Some examples are illustrative pseudocode and may need adjustment to match the exact syntax in the current Cambridge 9618 pseudocode guide. Confirm prescribed syntax, especially declarations, CASE, subroutines, built-in functions, strings and files, before using those examples as examination model answers.
