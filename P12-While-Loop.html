WHILE loop

A WHILE loop is a pre-condition loop: the condition is checked before each iteration.

PurposeSyntaxExamplesPractice & test

1 · Purpose

WHILE tests its condition before each iteration. The body executes only while the condition is TRUE, so the loop may execute zero times. The algorithm must change a value so that termination can eventually occur.

Core principle: The condition is checked before the body.

2 · Syntax and worked examples

Formal syntax

WHILE <Boolean condition>
  <statements>
ENDWHILE
  • The condition is checked before the body.
  • If the condition is FALSE initially, the body executes zero times.
  • Ensure each iteration progresses toward a condition becoming FALSE.
  • Use WHILE when repetition depends on a condition rather than a known count.

Worked examples with reasoning

Worked example 1 · Countdown
Count ← 5
WHILE Count > 0
  OUTPUT Count
  Count ← Count - 1
ENDWHILE

Outputs 5 to 1. Count decreases each iteration; the loop ends at 0.

Worked example 2 · Process positive values
INPUT Number
WHILE Number > 0
  Total ← Total + Number
  INPUT Number
ENDWHILE

The sentinel/non-positive value ends the loop and is not added to Total.

Worked example 3 · Repeated subtraction
WHILE Number > 9
  Number ← Number - 9
ENDWHILE

The number decreases by 9 each time until it is no longer greater than 9.

Common examination errors

  • No update to the loop-control variable, causing an infinite loop.
  • Using a condition that is false initially when at least one execution is required.
  • Reading the next input at the wrong point, causing the same value to be processed repeatedly.

Independent practice · reveal guidance after attempting

Zero iterations

If Count starts at 0, how many times does WHILE Count > 0 run?

Check your response: Zero times, because the condition is false at the first test.

Prevent an infinite loop

A loop uses WHILE X < 10 but never changes X. Explain the fault and fix it.

Check your response: Update X in the body so the condition can eventually become false.

Choose a loop

Input is repeated until the user enters -1. Which loop is suitable and why?

Check your response: WHILE is suitable when checking a sentinel before processing; REPEAT is suitable when input must happen at least once.

Five progressive worked examples

Worked example 4 · Extension

Validate input

INPUT Age
WHILE Age < 0 OR Age > 120
  OUTPUT "Try again"
  INPUT Age
ENDWHILE

Reasoning: The body executes only while the value is invalid.

Worked example 5 · Extension

Avoid an infinite loop

Attempts ← 0
WHILE Attempts < 3
  OUTPUT "Try"
  Attempts ← Attempts + 1
ENDWHILE

Reasoning: The update ensures the loop condition eventually becomes false.
