INPUT

INPUT obtains a value from the user and stores it in the named variable.

PurposeSyntaxExamplesPractice & test

1 · Purpose

INPUT transfers a value supplied by the user into a variable. Input statements should follow declarations and precede any calculation that depends on the entered value.

Core principle: The destination must be a variable or a valid element of a data structure.

2 · Syntax and worked examples

Formal syntax

INPUT <variable or valid data item>
  • The destination must be a variable or a valid element of a data structure.
  • Input all values needed before using them in calculations.
  • Consider validation when the problem requires a value to fall within a permitted range; INPUT alone does not validate data.

Worked examples with reasoning

Worked example 1 · Read one value
DECLARE Age : INTEGER
INPUT Age
OUTPUT Age

The entered value is stored in Age and can then be used.

Worked example 2 · Read and calculate
DECLARE Width : REAL
DECLARE Height : REAL
DECLARE Area : REAL
INPUT Width
INPUT Height
Area ← Width * Height
OUTPUT Area

Both dimensions must be obtained before calculating the area.

Worked example 3 · Input with validation loop
DECLARE Score : INTEGER
REPEAT
  INPUT Score
UNTIL Score >= 0 AND Score <= 100
OUTPUT Score

The post-condition loop repeats until the entered score is in range. INPUT itself does not enforce the range.

Common examination errors

  • Calculating with a variable before it has been assigned a value.
  • Assuming user input is automatically valid.
  • Using OUTPUT where INPUT is required, or attempting to input into a constant.

Five progressive worked examples

Worked example 4 · Extension

Validate an input range

INPUT Choice
WHILE Choice < 1 OR Choice > 4
  OUTPUT "Enter 1 to 4"
  INPUT Choice
ENDWHILE

Reasoning: The condition describes invalid values; input is repeated until valid.

Worked example 5 · Extension

Read until a sentinel

Total ← 0
INPUT Value
WHILE Value <> -1
  Total ← Total + Value
  INPUT Value
ENDWHILE

Reasoning: The sentinel terminates input and is not added to the total.
