Built-in functions

Built-in functions provide ready-made operations supported by the pseudocode specification or programming environment.

PurposeSyntaxExamplesPractice & test

1 · Purpose

A built-in function performs a defined operation and returns a value. Cambridge may provide the specification of a function in the question; candidates should use the given definition rather than assume an unfamiliar function’s behaviour.

Core principle: Check the function’s parameter types, number of arguments and return type.

2 · Syntax and worked examples

Formal syntax

FunctionName(argument(s))
  • Check the function’s parameter types, number of arguments and return type.
  • LENGTH returns string length; LEFT/RIGHT/MID-style functions should only be used according to the supplied specification. The 9618 guide explicitly describes LENGTH, RIGHT, MID, LCASE, UCASE, INT and RAND.
  • INT returns the integer part of a REAL value; RAND(x) returns a random REAL from 0 inclusive to x exclusive.
  • Do not invent the behaviour of a function that the question defines for you.

Worked examples with reasoning

Worked example 1 · String length
DECLARE UserName : STRING
UserName ← "Ravi"
NameLength ← LENGTH(UserName)

NameLength is 4.

Worked example 2 · Extract a substring
Part ← MID("ABCDEFGH", 2, 3)

Using Cambridge’s definition, this returns "BCD": start at position 2 and take 3 characters.

Worked example 3 · Convert a real to integer part
WholePart ← INT(27.5415)

WholePart becomes 27. INT returns the integer part, not a rounded value.

Common examination errors

  • Assuming string positions begin at 0 when the guide’s example uses position 1 as the first character.
  • Treating INT as rounding to the nearest integer.
  • Calling a function with the wrong number or type of arguments.
